DECISION NOTES

值得做，但先做两屏；不要把浅色反相。

编辑区是一整张纸，夜里它就是房间里最大的光源——这是夜间模式对这个产品最实在的理由。但它成立的条件不是「把颜色调暗」，而是重新定一套纸：暖墨紫的桌面、深栗的纸、米白的墨、提亮的樱，硬偏移阴影换成更深的黑。否则会掉进通用深色仪表盘，和 01 的手帐身份断掉。

范围

先做工作台 + 编辑器两屏，覆盖 90% 使用；设置/解锁/组件随 token 自动获得。

身份

纸胶带、索引卡、提交小票、圆形印章、唯一实心樱粉按钮全部保留。

代价

约 60 处颜色字面量收敛到 token，加 1 个设置项与 1 段启动脚本；无新增依赖。

边界

不动 gateway、frontmatter 字段、提交协议与加密；只换外观层。

评审后修订 · v2

你提的问题里，大部分成立，已经改在这一版里；有两类建议没有照做，原因写在后半段。

危险 ≠ 品牌

夜间 danger 从粉调偏前红：#FF97A7 → #FF8F7C，与品牌粉 #F07CA3 色相相差约 31°（340° vs 9°）。删除、冲突、重置只用 danger；粉色只留给 CTA、印章、当前项。

粉色面积

索引卡图标换成卡片式，夜间直接上白色（文件夹 #FFFFFF、文件 78% 白），不再用粉/灰；选中行底色从高饱和梅红降到 #3E2B33；语法标记降饱和为 #D99AAE / #A9C9BB；活动行 tint 从 10% 降到 8%。

元数据与输入

muted 提亮 #A8968F → #B3A19A（5.66 → 6.37）；placeholder #A5918A → #B5A39B（5.35 → 7.28）；输入框边框 #857078 → #8F7A82（3.50 → 3.96），输入底比纸暗一档，边界更清楚。

纸张边界

纸面 #281F24 → #2A2025、桌面 #120D10 → #100B0E；便签底色各提一档；纸边线 #7B646B → #806970（3.13:1）；阴影加深。卡片与背景不再糊在一起。

印章

从亮粉改成偏深的印泥红 #E06582（4.77:1），减少暗底上的发光感；实心粉按钮仍然只有「新建文章」。

没有照做

不用纯黑纸面 + 纯白正文：大面积中文长文在纯黑/纯白上的光晕与对比更累眼；保留暖墨纸 #2A2025 + 米白墨 #F2E6DE（12.88:1）。也不把状态色合并成一套灰阶：草稿 / 加密 / 置顶需要颜色 + 文字同时辨认，灰阶会削弱扫读。

附：评审中两处读数与实现不符——占位符实测是 5.35（不是 4.13），选中行的文字是米白而不是粉色；这一版仍把两者都往更清楚的方向调了：占位符 7.28，选中行底色降到梅灰。

同一张编辑纸，昼与夜

内容、字号、结构完全一致，只换 token。注意三件事：纸仍然是不透明的；代码块是比纸更深的「墨池」；印章仍然是唯一的红。

风险对策
纸感塌成通用深色仪表盘暖墨紫桌面 + 深栗纸 + 米白墨 + 深黑硬阴影；拒绝纯灰、玻璃与发光。
长文对比过强，夜里反而刺眼正文不用纯白（#F2E6DE），纸不用纯黑（#2A2025）；12.9:1 但低蓝光，连续阅读更柔。
代码块 / 表格反色后层级乱代码块用比纸更深的「墨池」；表头用深腮红而不是灰。
首屏白闪 / 系统偏好冲突head 内联脚本先应用主题；默认跟随系统；手动选择后记住；color-scheme 同步。
「唯一实心粉按钮」规则被破坏夜间主按钮改成粉底深字（6.99:1），仍然只允许「新建文章」；印章继续描边。
视觉回归成本翻倍用 token 级对照 + 两套 golden 截图，不做逐像素追查。
做了没人用先只做两屏，观察系统偏好命中率；一周内没人切夜就不补齐设置项。

如果做，按这个顺序

  1. 先把颜色字面量收进 --abs-*：app.css 组件层、CodeMirror 主题、预览排版、6 处 white 类。
  2. 加主题状态：设置项 + 启动脚本 + color-scheme；设置页补「外观」纸。
  3. 按本页 token 表过工作台与编辑器两屏；设置/解锁只做抽查。
  4. 补 1440 / 390 / 系统偏好切换三档截图验收，复跑对比度。
  5. 在 DESIGN.md 增补夜间 token 与规则，README 加「外观」设置说明。

不做什么

  • 不做 CSS 反相滤镜——图片、代码、印章全部失真。
  • 不做玻璃拟态 / 发光 / 渐变边——那是 02 夜樱电台被否掉的部分。
  • 不用纯黑纸面与纯白文字——对比过硬，长文刺眼。
  • 不做多套皮肤 / 主题编辑器——先验证「夜」这一套是否真被使用。
  • 不动 gateway、字段、提交与加密协议——主题只是外观层。
最小验证

如果不想动设置页：只做 token 覆盖 + CodeMirror/预览修正，默认跟随系统，三处改动就能观察一周。确认有人用，再补手动切换与设置纸。
