# 视觉方向选型 Brief

## 任务

为 Astro Blog Studio 选一个视觉方向：同一个工作台，4 种真正不同的世界。不是换配色，而是换构图、卡面语言、字体、动效节奏和签名交互。

## 交付

- `astro-blog-studio/design/directions.html`：**一个自包含 HTML 文件**，顶部切换 4 个方向 + 对比页。
- 每个方向 5 个视图：工作台 / 编辑器 / 设置 / 解锁 / 组件标本。
- 4 个方向共用同一套样例数据，保证对比公平。
- 你可以直接双击打开，也可以点「选择这个方向」，然后把编号/名字告诉我。

## 同一个产品事实（所有方向共用）

- 仓库 `yukino/astro-blog-content`，分支 `main`，根目录 `src`，可见 164 个 Markdown。
- 选中文档：`src/content/blog/note/便笺-Markdown-备忘单.md`。
- 有草稿、置顶、加密、长 CJK 标题、被排除的 en/ja 目录。
- API 余量 4,812 / 5,000；保存会产生 1 个提交。
- 提交消息模板：`update: {path}`。

## 评判维度

1. **辨识度**：去掉内容后，仅凭色彩、字体、卡面和装饰还能认出是哪个方向吗？
2. **编辑专注**：编辑面和正文阅读是否安静、清晰、可长时间使用？
3. **信息层级**：树、文章列表、frontmatter、预览、保存状态是否一眼可辨？
4. **签名交互**：有没有一个从产品里长出来、别处抄不到的动作？
5. **可实施性**：1440 / 1024 / 390 都能成立；不依赖不可用素材；动效可降级。
6. **风险**：哪种方向最容易滑向模板脸、廉价感或可读性下降？

## 硬约束

- 不使用动漫角色立绘、参考站素材、第三方图标瓷砖。
- 不做居中 hero + 三张功能卡、紫蓝渐变、玻璃卡片堆叠、shadcn 默认仪表盘。
- 正文 ≥ 4.5:1，非文本 UI ≥ 3:1；颜色不是唯一状态。
- 编辑区（写正文的地方）不做纹理、不做旋转、不做入场动画。

## 我的看法（不代替你的选择）

- A 樱糖手帐：最贴合你给的柔和二次元参考，也最有「写博客」的手感；风险是可爱外壳干扰写作。
- C 原稿纸：最耐看、最适合长时间写作；风险是中文衬线可用性。
- B 夜樱电台：最适合夜间；风险是深色长文与玻璃拟态俗套。
- D 薄荷汽水：最有趣；风险是 kitsch 和可读性。

选定后我会把它做到完整，不做「更安全的一半」。
