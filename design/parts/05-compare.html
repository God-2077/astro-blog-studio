四个方向，放在一起看

同一套样例数据、同一批视图。差异不在颜色，而在构图、卡面、字体关系和动效节奏。选一个你愿意每天打开两次的。

樱糖手帐 01

把编辑器做成一张摊在桌上的纸：索引卡找文件，夹板看预览，盖章完成提交。

字体
Zen Maru Gothic / 系统中文 / Sometype Mono
形态
纸胶带、索引卡、印章、硬偏移阴影
动效
240ms 弹簧（仅外壳）/ 盖章 320ms
签名
盖章存档 + 提交小票

风险：可爱外壳可能干扰写作；用「编辑区极安静」的硬规则约束。

夜樱电台 02

把写作做成深夜放送：脚本、监听、波形；未保存是波形抖动，保存是 ON AIR → SAVED。

字体
Sora / Martian Mono / 系统中文
形态
1px 渐变边、实心文字面、波形、竖向标签
动效
14s 环境光漂移 / 180ms 切换
签名
脏状态波形 / 归档光扫

风险：深色长文与玻璃拟态俗套；文字区必须不透明、高对比。

原稿纸 03

把编辑器做成一张校样：页边编号、colophon 元数据、朱批和一枚「校了」印。

字体
Shippori Mincho / 系统中文 / Sometype Mono
形态
细线、无卡片、页边数字、纸纹、印章
动效
120ms 淡入 / 无弹跳
签名
colophon frontmatter + 校了印

风险：中文衬线可用性；不依赖下载 CJK 衬线做正文。

薄荷汽水 04

把工作台做成 2000 年代日系个人站后台：窗口、文件柜、街机保存键和一条跑马灯。

字体
DotGothic16 / 系统中文 / Sometype Mono
形态
斜面高光、窗口标题栏、点线、贴纸
动效
90–120ms 阶梯 / 跑马灯 18s
签名
街机保存键 + 状态跑马灯

风险：kitsch 与可读性；像素字只做短标签，正文用正常无衬线。

我的看法

如果只按你给的参考调性，01 樱糖手帐最贴：柔和粉彩、轻二次元、有手作感，而且「盖章存档」这件小事让保存有了仪式感。它的风险也很清楚——外壳越可爱，编辑区越要安静。

如果按「每天写两小时」的耐用度，03 原稿纸最稳：没有卡片堆叠，靠字体、留白和页边信息建立秩序；它也是四个里最不像 AI 模板的一个。

02 适合夜间，但深色 + 玻璃最容易滑向俗套；04 最有趣，也最容易过火。选定后我会把它做到完整，不做安全的一半。

硬约束自检

  • 无动漫角色立绘、无参考站素材、无第三方图标瓷砖。
  • 无居中 hero + 功能卡、无紫蓝渐变、无玻璃卡片堆叠。
  • 编辑区不做纹理、旋转、入场动画。
  • 正文 ≥ 4.5:1，非文本 UI ≥ 3:1；颜色不是唯一状态。
  • 1440 / 1024 / 390 三档都成立；动效可降级。

怎么选

点方向右上角的「选择这个方向」，或者直接告诉我编号/名字。选定后我会写方向契约，再开始实现完整应用。
